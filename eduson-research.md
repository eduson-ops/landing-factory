# Eduson Academy — структура лендингов (research, 2026-05-11)

Источник: краулинг 11 курсов через WebFetch + curl. Платформа — **Tilda CMS** (не React/Next.js), HTML доступен сразу.

## Курсы

OK: `/operations-director`, `/python`, `/project-manager`, `/data-analyst`, `/hr-manager`, `/medical-director`, `/gen-dir`, `/business-analyst`, `/mba-all`, `/web-designer`, `/copywriter`
404: `/ai-engineer`, `/digital-marketing`

## Каноничный порядок (агрегат)

1. Hero + скидка -60% + CTA
2. **Форма записи #1** (прямо под hero, часто всплывающая)
3. Ключевые преимущества (3-4 пункта: гарантия трудоустройства, практика, диплом)
4. Целевая аудитория (3-4 типа слушателей)
5. Описание профессии — где работают, зарплаты
6. Статистика по результатам (% трудоустройства, опыт выпускников)
7. Навыки / инструменты (таблица или сетка, 20-30+ позиций)
8. Методы обучения (видео, практика, проекты, тесты)
9. Программа курса (заголовок «N модулей, K уроков»)
10. Подробное описание программы (развёртка модулей)
11. Портфолио — 8-10 практических проектов
12. Стажировка / трудоустройство (PointPulse для Python, ReGroup и др.)
13. Диплом / удостоверения (часто 2 типа на одной странице)
14. Преподаватели — 3-5 профилей
15. Отзывы — карусель 5-8, рейтинг ~4.8
16. AI / нейросети блок (на новых курсах)
17. **Форма записи #2** (в конце страницы)

## Контентные паттерны

- **Hero h1:** «<профессия> — <ценностное обещание>»
- **Скидка:** всегда -60%, дедлайн «до конца дня/недели»
- **Программа:** «X модулей, Y уроков» (примеры: 36/320, 8/44, 194 уроков)
- **Зарплаты:** диапазон junior / mid / senior
- **Диплом:** обычно 2 типа — удостоверение о повышении квалификации (гос. образец) + сертификат Eduson
- **Отзывы:** «Имя + должность (компания) + текст + рейтинг», рейтинг 4.7-4.9
- **FAQ:** встречается редко, 5-6 стандартных вопросов

## Бренд-ассеты

- Рейтинги-агрегаторы: Яндекс, Сравни, Habr, SmartRanking
- Партнёры-работодатели: PointPulse, ReGroup, Сбер, Яндекс, EPAM, VK, X5 Retail
- Диплом: лого Eduson + триколор (для гос. образца) + макет печати

## Особенности по категориям

- **MBA / бизнес (gen-dir, mba-all):** доп. блок «цитаты экспертов» (Ицхак Адизес), чек-листы/шаблоны, «второй курс в подарок», цены 8-40K₽/мес рассрочка
- **IT (python, web-designer, business-analyst):** акцент на портфолио, детальный стек инструментов, стажировка через партнёра, цены 50-300K₽
- **Управленческие (ops-dir, pm, hr):** развёрнутая «целевая аудитория», статистика трудоустройства, упор на кейсы

## Что есть в нашем CATALOG, чего нет у Eduson

- `pain-01` — у Eduson нет блока «боли», есть только описание профессии/преимуществ. Возможно, лишний.

## Что есть у Eduson, чего нет в нашем CATALOG

- Дубликат CTA-формы (вторая внизу страницы) — у нас одна
- Блок «методы обучения» отдельно от формата — у нас format-01 это микс
- «Социальное доказательство» от экспертов с цитатами (не выпускники, а внешние авторитеты) — для MBA-курсов
- Чек-листы / шаблоны для скачивания — для бизнес-курсов
- «AI/нейросети» как выделенный блок — для новых курсов
